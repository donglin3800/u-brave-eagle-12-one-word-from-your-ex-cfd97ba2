One word, the word my ex would use to describe me: **exhausting**. It is the
word exes actually say in the breakup fight, and the one you cannot argue
with, because you know the second you hear it that you did wear them out.
It lands instantly, it stings because it is true, and everybody who has
ever dated someone intense has either said it or heard it.

## Run it

```sh
python3 main.py
```

The program writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(`entry.txt`, 10 characters, no trailing newline).
